# Ski Journal (Dryland Training)

A React-based web application for tracking dryland ski training.

## Features

- **Phase Management**: Global setting for Phase 1 (Capacity), Phase 2 (Utilization), and Phase 3 (Maintenance).
- **Leg Blasters**: Guided workout tool with Mini (10/10/10/5) and Full (20/20/20/10) templates and a built-in rest timer.
- **TJT Calculator**: Automatically calculates your daily 25% EMOM target based on your 2-minute max reps.
- **Data Privacy**: All data is stored locally in your browser (`localStorage`). No backend database.
- **Export**: Export your workout history to CSV.

## Tech Stack

- React (Vite)
- Tailwind CSS v4
- Lucide React Icons

## Getting Started

1.  Install dependencies: `npm install`
2.  Start development server: `npm run dev`
3.  Build for production: `npm run build`
